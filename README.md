# ArcaneComposer

A deck maker UI for [Era of Arcane](https://yifeeeeei.github.io/EraOfArcane)

## New card schema preview

This temporary build reads the test-card metadata generated by
`arcane_go`'s `feature/new-card-schema` branch:

- Metadata: `https://raw.githubusercontent.com/Yifeeeeei/ArcaneImages/main/new_output/all_card_infos.json`
- Card images: `https://raw.githubusercontent.com/Yifeeeeei/ArcaneImages/main/new_output/...`
- Card IDs are strings such as `BAC001`, `BFS001`, and `BAI001`.
- `cost:` and `mana:` filters use `mana_cost`; `set:`, `rarity:`, and
  `subtype:` are also supported.
- Cards with rarity `衍生` are shown in a separate derived-card section. When
  a card is added, legacy structured `spawns` relationships are translated
  through the new cards' `art_ref` values and matching derived cards are added
  automatically without duplicates.
- The card-pool sort buttons sort by `mana_cost`.
